The research half of the agent workflow, packaged. dragon-agents is a local plugin for the ZCode agent client: twenty-nine subagents. Twenty are read-only: restricted to Read and Bash, forbidden from committing or spawning subagents of their own; they gather and report. Nine carry chartered write lanes, and every lane runs inside a structural fence: a named scope, a clean-tree precondition, a re-verification step, and never a commit. The point is unchanged, only sharper: writes are safe exactly where the gate is structural, so the fences let the fixing scale without the deciding moving an inch.

- **repo-cartographer**: a structured repo map (layout, stack, conventions, tests, risk areas) before planning sessions.
- **doc-drift-auditor**: standard-layout docs versus code reality: VERSION sync, roadmap boxes, spec claims, patchnotes hygiene.
- **cascade-checker**: a downstream call-site inventory for a changed shared-library API, with per-repo breakage risk.
- **spec-compliance-reviewer**: a diff against the `spec.md` contract; violations and unaddressed claims with `path:line` evidence.
- **ci-triage**: a failed CI run reduced to root cause, decisive log lines, and fix direction.
- **slop-reader**: a fresh-eyes AI-prose pass on commissioned docs; it flags quotes and never rewrites.

The v0.2.0 wave added ten more: **release-auditor** (pre-tag readiness checks and post-tag sweeps), **workspace-sentinel** (a one-dispatch status sweep across every repo in the workspace), **ci-posture-auditor** (workflows graded against the house-hardened CI shape), **debt-census** (TODO/FIXME markers dated by blame into a cleanup worklist), **code-reviewer** (bug-hunting over a diff), **git-archaeologist** (regression windows and provenance from history), **claim-verifier** (independent re-verification of a findings list), **dependency-auditor** (declared versus imported dependencies, version floors versus the APIs actually used), **test-gap-analyst** (static test-coverage maps), and **duplication-scout** (cross-repo duplicate candidates feeding library-graduation decisions).

The waves since pushed past repo walls and grew the roster to twenty-three: **stock-broker** (v0.3.0: markets and fundamentals briefs from keyless public sources: SEC filings, XBRL fundamentals, quotes across asset classes, and macro series), then the personal-data four of v0.4.0: **ledger-analyst** (hledger finance briefs, fenced off from the encrypted finance files until a readable journal exists), **librarian** (Calibre library research through [cquarry](/codex/cquarry/)'s read surface), **data-analyst** (read-only duckdb profiling of dispatch-named datasets), and **security-auditor** (defensive review of owned repos: secret scans, risky-pattern review, advisory cross-checks). **charter-architect** (v0.5.0) is the roster's meta lane: it designs new agents, scorecards the candidate, and returns the complete release kit as text. **syshealth-auditor** (v0.6.0) watches the machine itself: backup freshness and system health from state reads, with passphrase-gated checks fenced and reported as directions.

v0.7.0 reworked **librarian** into the books-core research lane (cquarry's read modes, bindery's audit battery of doctor/audit/observe, the library's own validator, and read-only duckdb joins) and added **music-archivist**: music-collection research over [lattice-music](/codex/lattice/)'s read-only audit surface (health digest, genre hygiene against the tree's own taxonomy, duplicates, codec coverage, listening candidates), every lattice write mode fenced. v0.7.1 hardened both for portability.

v0.8.0 through v1.1.0 amended the founding rule, deliberately and in the open. **claw** (v0.8.0) executes the Calibre acquisition pipeline's import phases behind the pipeline's own structural gates, with **shadow** as its read-only phase gate. v0.9.0 chartered five audit-and-fix seats that apply the mechanical fixes their own audits find, each verified by re-running the audit: **charter-architect** (its own approved release kits), **ci-posture-auditor** (the hardened CI shape, tightening only), **doc-drift-auditor** (version carriers, roadmap ticks, patchnotes hygiene), **debt-census** (dispatch-named removals), and **test-gap-analyst** (the named missing tests, written and run, production code untouched). v1.0.0 added the purpose-built writers: **latro** (deep web research delivered as one new cited markdown report per dispatch; no Edit tool, overwrite refused, keyless sources only) and **assay** (whole-repo report cards on five metrics whose goals append to roadmap.md only, re-verified zero-deletion, plus read-only grading of new ideas). v1.1.0 added **imprint**, which tends a repository's GitHub description and topics through two gh verbs, propose-first, read-back verified: the roster's first writes that publish instantly. The same releases upgraded **slop-reader** with second-order detection: the compensation patterns of prose hiding its slop, and the evasion artifacts of prose hiding the hiding, calibrated so the workspace's own no-em-dash house style is never mistaken for a tell. v1.2.0 closed the gap survey's one read-side finding with **schedule-analyst**, the weekly school-and-schedule digest (Todoist through td, cross-referenced with gcalcli agendas, recommendations only, never a task write), and recorded the survey's verdict that the write axis is saturated.

A stdlib-only structure validator (both manifests plus every agent charter: frontmatter fields, per-class tool sets, the read-only line for readers, the fence literals each write class must carry, the no-subagent line everywhere, and the thirty-agent roster) runs in CI on every push, and the repo documents the proven plugin refresh procedure end to end. Built for personal use; installed through a directory marketplace.
